# Warsaw

Robot condition monitoring, protective shutdown and device identification.

## Status

Early-stage concept and proposed low-energy bench demonstrator.
No completed hardware build, validated safety function, measured performance or certification is claimed.

## Objective

- Monitor selected sensor inputs.
- Detect predefined fault conditions.
- Disable a low-energy simulated robot function.
- Keep fault stops latched until deliberate recovery.
- Separate reset from restart.
- Report device identity and operating state.
- Record significant events.

## Safety boundary

Protective shutdown means non-destructive disabling of the demonstration output.
This project is not intended for hazardous machinery or operational humanoid control.
